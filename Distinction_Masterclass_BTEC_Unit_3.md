#### Activity B: Constraints vs. Assumptions vs. Risks (15 Mins)

**Context (Part A):** Students often mix these up. The Examiner noted that "constraints and assumptions... in a lot of cases were irrelevant or far too generic."

**Task:** Sort the following statements from the Battleford Scenario into the correct column.

| **Statement** | **Insert Statement Number (1-4)**  |
|----------------|----------------------------------|
| "The budget is strictly £45,000." |                          |
| "Staff will work 5 days a week, 7.5 hours a day." |      |
| "The Senior Software Engineer might be pulled onto another project." |                      |
| "The project must start on 7th February."             |

| **Category**               | **Definition**                                                       |
|----------------------------|-----------------------------------------------------------------------|
| **Constraint**            | A restriction fixed by the client that you cannot change.            |
| **Assumption**            | Something you believe to be true for planning, but isn't guaranteed. |
| **Risk**                  | A future event that might happen and negatively impact the project.  |

#### Activity C: The "Lessons Learned" Transformation (15 Mins)

**Context (Part B):** This is the most critical section for the Distinction grade. The Examiner's Report states students often just describe "what they did rather than what they would do differently in future projects."

**The "So What?" Method:**

- **Issue:** What went wrong?
- **Impact:** How did it hurt the project (Time/Cost/Quality)?
- **Lesson:** So what will you do differently in the next project?

**Task:** Complete the table below regarding the "Software Problems" issue found in Part B.

| **Step**     | **Detail**                              |
|--------------|-----------------------------------------|
| **The Issue**| Software problems occurred due to rushing. |
| **The Impact**| How did this affect the testing phase or budget? |
| **The Lesson**| (Distinction Step): Don't just say "I will plan better." Be specific about Time Management or Quality Control. |
